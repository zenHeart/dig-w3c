缓存策略对比
Cache First -> 缓存优先，未命中再请求网络。适合静态资源
Network First -> 网络优先，失败时回退缓存。适合 API 数据
Stale-While-Revalidate -> 立即返回缓存，同时后台更新。适合读多写少
Cache Only / Network Only -> 纯缓存或纯网络
