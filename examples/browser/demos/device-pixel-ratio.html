devicePixelRatio 交互演示

深入理解 DPR 的计算方式、实际应用场景，以及它如何影响 Canvas 渲染和图片显示。

1. 核心公式

devicePixelRatio = physical pixels / CSS pixels
当前 DPR
—
devicePixelRatio
物理分辨率
—
screen.width × screen.height
CSS 分辨率
—
window.innerWidth × innerHeight
CSS 像素对应的物理像素数
—
DPR² = 每个 CSS 像素包含的物理像素数

3. Canvas 高清适配对比

两张 Canvas 都声明 CSS 尺寸为 200×200px，实际像素缓冲区不同。

未适配高清（模糊）
已适配高清（清晰）
⚠️ 在 DPR=2+ 的设备上（如 Retina MacBook），左侧未适配 Canvas 会明显模糊。右侧通过 width×DPR, height×DPR, scale(DPR) 解决了这个问题。

4. DPR 与 DPI 对照

DPR × 96 ≈ 屏幕 DPI（近似值）。标准显示器 DPR=1 = 96 DPI。

5. 页面缩放对 DPR 的影响

放大页面（Ctrl/Cmd +）会让 CSS 像素变大，浏览器所见 CSS 分辨率降低，DPR 增大。

100%
CSS 分辨率 = 1920 / 1 = 1920 → DPR ≈ 1
📐 捏合缩放（Pinch Zoom）：仅放大视觉内容，不改变 CSS 分辨率，不影响 DPR。但 页面缩放（Page Zoom） 会同时改变两者。

7. DPR 变化监听

将浏览器窗口拖动到不同屏幕（不同 DPR），或在不同缩放级别间切换，查看实时变化。

监听方式：
const mq = window.matchMedia( `(resolution: ${window.devicePixelRatio}dppx)` ); mq.addEventListener('change', () => { console.log('DPR changed to', window.devicePixelRatio); });
