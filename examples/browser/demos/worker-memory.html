💡 关键知识点

核心结论：Worker 运行在独立 V8 堆，不直接占用渲染进程主线程内存。 这意味着即使 Worker 处理大量数据，主线程的性能也不会受影响。
postMessage 行为：
  • 默认：使用结构化克隆，数据会被完整拷贝
  • Transferable：所有权转移，零拷贝（如 ArrayBuffer）
  • SharedArrayBuffer：共享内存，双方可见修改
内存影响：传递大对象时要注意：
  • 默认拷贝会占用双倍内存（发送方 + 接收方）
  • 使用 Transferable 可避免拷贝，提升性能
  • Worker 终止后其堆内存会被回收

如何在 DevTools 中验证： 打开 Chrome DevTools → Memory 面板 → Take heap snapshot， 可以看到 Main Thread 和 Worker 有独立的 VM Context。
