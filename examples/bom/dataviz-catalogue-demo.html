什么是 Data Visualization Catalogue？

Data Visualization Catalogue（数据可视化目录）是一个由 Severino Ribecca 创建的在线图表百科全书。与传统的按"形状"分类（柱状图、饼图等）不同，它按照你想要完成的任务来组织图表。

核心优势：

  • 任务导向 — 从"我想做什么"出发，而非"图表长什么样"
  • 详细说明 — 每个图表都有使用场景、优缺点、最佳实践
  • 搜索功能 — 快速找到适合的图表

📊 比较类（Comparison）

适用：比较不同类别之间的值的大小关系

图表说明适用场景
柱状图 Bar Chart用柱子高度表示数值大小类别不多（<10）时的离散比较
分组柱状图 Grouped Bar每组多个柱子多个子类别在同维度下的比较
堆叠柱状图 Stacked Bar柱子堆叠显示组成部分与整体 + 类别比较
南丁格尔玫瑰图 Nightingale Rose极坐标下的面积图周期数据比较（如24小时数据）
雷达图 Radar Chart多维数据轮廓对比能力模型、特征对比
子弹图 Bullet Graph柱状图 + 目标线实际值 vs 目标值对比
词云 Word Cloud文字大小表示频率文本数据高频词可视化

📈 分布类（Distribution）

适用：展示数据的分布形态、集中趋势、离散程度

图表说明适用场景

箱线图 Box Plot显示中位数、四分位数、异常值多组数据分布对比

瀑布图 Waterfall Chart柱状递增/递减数量增减过程的分解

图表颜色使用指南

1. 类别区分（Categorical）

用于区分没有顺序的类别。使用色调差异大的颜色，4-8 色为宜。

#3b82f6
#ef4444
#10b981
#f59e0b
#8b5cf6
#06b6d4
// D3 类别色标示例 const categoryColors = [ '#3b82f6', // 蓝 '#ef4444', // 红 '#10b981', // 绿 '#f59e0b', // 黄 '#8b5cf6', // 紫 '#06b6d4', // 青 ];

2. 数值大小（Sequential）

用于表示从低到高的连续数值。使用单色渐变（浅→深）。

#eff6ff
#bfdbfe
#60a5fa
#2563eb
#1d4ed8
#1e3a8a
// D3 顺序色标 import { scaleSequential } from 'd3-scale'; import { interpolateBlues } from 'd3-scale-chromatic'; const colorScale = scaleSequential(interpolateBlues) .domain([0, 100]); colorScale(0); // #f0f9ff (浅) colorScale(100); // #1e3a8a (深)

3. 正负对比（Diverging）

用于表示偏离中心值的正负两端。使用双色渐变，中间为中性色。

#dc2626 (负)
#f87171
#fecaca (中性)
#bbf7d0 (中性)
#4ade80
#16a34a (正)

4. 不要（Don'ts）

  • 不要用饼图比较超过 5 个类别 — 扇形太多难以阅读
  • 不要截断 Y 轴 — 柱状图从 0 开始，否则比例失真
  • 不要用 3D 效果 — 扭曲数据比例，造成误导
  • 不要用超过 8 种颜色 — 造成视觉负担，难以区分
  • 不要用彩虹色渐变 — 不是感知均匀的，数据解读困难
  • 不要忽略色盲友好 — 避免红绿组合，使用蓝橙等安全色
