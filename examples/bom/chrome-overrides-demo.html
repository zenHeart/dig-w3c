🔧 Chrome DevTools Overrides

Chrome 远程文件本地替换功能 — 交互式学习演示

什么是 Overrides？

Chrome DevTools Overrides（覆盖）功能允许将远程网络资源映射到本地文件，修改后刷新页面仍然生效。

🎯 核心用途
用途说明
🐛 调试线上问题不修改线上代码，直接在本地覆盖调试
🎨 修改线上样式临时调整 CSS，即时预览效果
🧪 模拟 API 响应后端未就绪时，返回本地 JSON 数据
🔓 绕过跨域限制覆盖 API 响应，前端开发无阻
🔑 关键特性
特性说明
持久化映射关系跨浏览器会话保存
透明劫持请求被拦截并返回本地文件
覆盖范围广支持 HTML/CSS/JS/图片/字体等所有资源
无需插件Chrome 内置功能，无需额外安装

启用与使用步骤

第一步：启用 Overrides
  1. 打开 Chrome DevTools（F12 或 右键 → 检查）
  2. 切换到 Sources 面板
  3. 点击左侧 Overrides 标签
  4. 点击 "+ Select folder for overrides"
  5. 选择一个本地目录存放覆盖文件
  6. 确认浏览器授权提示
第二步：覆盖文件
  1. 切换到 Network 面板
  2. 找到要覆盖的资源（CSS/JS/JSON/图片等）
  3. 右键点击该资源
  4. 选择 "Save for overrides"
  5. 文件自动保存到之前选择的覆盖目录
第三步：修改并生效
  1. 在 Sources 面板找到覆盖的文件（带紫色点）
  2. 编辑文件内容
  3. 刷新页面（Cmd+Shift+R 强制刷新效果最佳）
  4. 页面加载时使用本地覆盖文件

持久化原理

Overrides 的持久化依赖于 Chrome DevTools 内部的映射表，记录了远程 URL 到本地文件路径的对应关系。

🔍 映射表结构
DevTools 内部映射表示例：

{
  "https://example.com/styles/main.css":
    "/Users/你的名字/Chrome-Overrides/example.com/styles/main.css",

  "https://example.com/scripts/app.js":
    "/Users/你的名字/Chrome-Overrides/example.com/scripts/app.js",

  "https://api.example.com/data.json":
    "/Users/你的名字/Chrome-Overrides/api.example.com/data.json"
}
🔄 请求处理流程
1. 页面发起网络请求 → fetch('/api/data.json')
↓ DevTools 拦截请求
2. 检查 Overrides 映射表
↓
3a. 命中映射 → 读取本地文件 → 返回内容
        ↳ 文件不存在则清除映射，发送真实请求
3b. 未命中映射 → 发送真实网络请求
💾 持久化位置
数据存储位置说明
映射表Chrome DevTools 配置保存在浏览器配置中
覆盖文件用户选择的本地目录可纳入 Git 版本控制
启用状态Overrides 面板勾选状态重启浏览器后保持
⚠️ 数据丢失风险

以下操作会导致 Overrides 映射丢失：

  • 清除浏览器数据（尤其是"浏览数据"）
  • 重置 Chrome 设置
  • 卸载并重新安装 Chrome

预防措施：将覆盖文件目录纳入 Git 版本控制，定期提交。

Overrides vs Workspace

Chrome DevTools 提供了两种文件映射功能，适合不同场景。

Overrides

  • 适合临时调试线上问题
  • 文件保存在用户选择目录
  • DevTools 内部维护映射
  • 跨会话持久化
  • 不影响页面实际请求路径

Workspace

  • 适合日常开发调试
  • 直接将本地目录映射到 URL 路径
  • 文件变更直接生效
  • 需要配置文件映射规则
  • 真正替代远程资源

版本控制可纳入 Git本身就是源码
适合场景线上 Bug 快速修复项目开发调试
