二维码（QR Code）识别技术交互演示

QR 码结构

定位图形

三个角落的方块，用于定位 QR 码位置

校正图形

帮助校正角度和位置，版本 2+ 出现

数据和纠错

存储实际数据及 Reed-Solomon 纠错码

纠错级别

级别可恢复特点
L (Low)7%最大容量，适合干净环境
M (Medium)15%平衡之选（默认）
Q (Quartile)25%适合可能受损的场景
H (High)30%最高可靠性，工业用途

WiFi 格式详解

WIFI:T:WPA;S:MyNetwork;P:password;;
  │  │      │            │
  │  │      │            └─ 密码
  │  │      └─ SSID（网络名称）
  │  └─ 加密类型（WPA/WEP/nopass）
  └─ WiFi 前缀
加密类型 (T:)说明
WPAWPA/WPA2 安全
WEPWEP 安全（已淘汰）
nopass无密码（开放网络）

类型检测代码

function detectQRType(data) {
  if (/^https?:\/\//.test(data)) return 'URL';
  if (/^tel:/.test(data)) return '电话';
  if (/^sms:/.test(data)) return '短信';
  if (/^mailto:/.test(data)) return '邮件';
  if (/^WIFI:/.test(data)) return 'WiFi';
  if (/^BEGIN:VCARD/.test(data)) return 'vCard';
  if (/^BEGIN:VCALENDAR/.test(data)) return '日历事件';
  if (/^MECARD:/.test(data)) return 'MECARD';
  if (/^bitcoin:/.test(data)) return 'Bitcoin';
  if (/^geo:/.test(data)) return '地理位置';
  return '文本';
}

BarcodeDetector API 检测 原生

使用浏览器原生 API 检测 QR 码

API 返回值结构

BarcodeDetectorResult {
  rawValue: "https://example.com",  // 解码后的数据
  format: "qr_code",                  // 格式类型
  boundingBox: DOMRectReadOnly {      // 边界框
    x, y, width, height
  },
  cornerPoints: [                    // 四个角点坐标
    { x, y },  // 左上
    { x, y },  // 右上
    { x, y },  // 右下
    { x, y }   // 左下
  ]
}

实时检测代码

const video = document.getElementById('video');
const canvas = document.getElementById('canvas');
const ctx = canvas.getContext('2d');

let detector;
let isRunning = false;

async function startDetection() {
  // 1. 获取摄像头
  const stream = await navigator.mediaDevices.getUserMedia({
    video: { facingMode: 'environment' }
  });
  video.srcObject = stream;

  // 2. 创建检测器
  detector = new BarcodeDetector({ formats: ['qr_code'] });
  isRunning = true;

  // 3. 检测循环
  detectLoop();
}

async function detectLoop() {
  if (!isRunning) return;

  canvas.width = video.videoWidth;
  canvas.height = video.videoHeight;
  ctx.drawImage(video, 0, 0);

  const barcodes = await detector.detect(canvas);
  if (barcodes.length > 0) {
    console.log('检测到:', barcodes[0].rawValue);
  }

  requestAnimationFrame(detectLoop);
}

原生 API vs JS 库对比

维度BarcodeDetector 原生jsQR JS
浏览器支持Chrome/Edge 83+所有现代浏览器
性能原生优化，更快依赖 JS 引擎
准确率高较高
离线使用需浏览器实现可打包进网站
维护浏览器厂商社区维护

选择建议

使用原生 API

仅需支持 Chrome/Edge，追求性能和准确性

使用 jsQR

需要跨浏览器兼容，离线环境使用

jsQR 基本用法 JS

// 引入 jsQR


// 检测 QR 码
const canvas = document.getElementById('canvas');
const ctx = canvas.getContext('2d');
ctx.drawImage(imageSource, 0, 0);

const imageData = ctx.getImageData(0, 0, canvas.width, canvas.height);
const code = jsQR(imageData.data, canvas.width, canvas.height);

if (code) {
  console.log('检测到:', code.data);
  console.log('位置:', code.location);
}
