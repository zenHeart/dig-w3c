navigator.sendBeacon

在页面卸载时可靠发送数据的 BOM API

什么是 sendBeacon？

`navigator.sendBeacon()` 是浏览器提供的 BOM API，专门用于在页面即将被卸载时可靠地发送小量数据到服务器。与传统的 `XMLHttpRequest` 和 `fetch` 不同，`sendBeacon` 保证请求会在页面关闭过程中被发送，不会因页面卸载而被取消。

核心特点

特性 说明
可靠发送 页面卸载时保证数据发送，不会被浏览器中断
异步非阻塞 不会阻塞页面卸载，不影响导航性能
仅 POST 始终使用 HTTP POST 方法发送数据
多格式支持 支持 ArrayBuffer, Blob, FormData, DOMString 等
无响应返回 无法获取服务器响应数据

基本语法

navigator.sendBeacon(url, data)

返回值

  • true — 浏览器已接受数据并即将发送
  • false — 无法将数据加入传输队列（极少见）

触发时机说明

// 推荐：使用 visibilitychange 事件（更可靠） document.addEventListener('visibilitychange', () => { if (document.visibilityState === 'hidden') { navigator.sendBeacon('/analytics', data); } }); // 不推荐：beforeunload 在移动端可靠性较低 window.addEventListener('beforeunload', () => { navigator.sendBeacon('/analytics', data); });

sendBeacon vs fetch + keepalive

两者都可以在页面卸载时发送请求，但有一些关键区别：

特性 sendBeacon fetch + keepalive
页面卸载时发送 ✅ 保证 ✅ 保证
异步非阻塞 ✅ ✅
获取响应数据 ❌ 不支持 ✅ 支持
请求方法 仅 POST 任意方法
数据格式 多种 多种
跨域请求 ✅ 支持 ✅ 支持
使用复杂度 简单 稍复杂

sendBeacon 示例

window.addEventListener('visibilitychange', () => { if (document.visibilityState === 'hidden') { navigator.sendBeacon('/analytics', JSON.stringify({ event: 'page_view', path: location.pathname })); } });

fetch + keepalive 示例

window.addEventListener('visibilitychange', () => { if (document.visibilityState === 'hidden') { fetch('/analytics', { method: 'POST', keepalive: true, headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ event: 'page_view', path: location.pathname }) }).then(res => console.log('服务器响应:', res)) .catch(err => console.error('发送失败:', err)); } });

如何选择？

  • 使用 sendBeacon：不需要服务器响应，只需确认数据送达；发送的数据较小；实现简单的埋点场景
  • 使用 fetch + keepalive：需要获取服务器响应；使用 GET 请求；发送的数据较大；需要错误处理

最佳实践

1. 结合 visibilitychange 事件

推荐使用 `visibilitychange` 事件而非 `unload`/`beforeunload`：

// ✅ 推荐：visibilitychange 在移动端更可靠 document.addEventListener('visibilitychange', () => { if (document.visibilityState === 'hidden') { navigator.sendBeacon('/analytics', data); } }); // ⚠️ 谨慎：beforeunload 在移动浏览器中可能不触发 window.addEventListener('beforeunload', () => { navigator.sendBeacon('/analytics', data); });

2. 数据大小注意

虽然规范没有限制，但浏览器通常对数据大小有限制（通常几 MB）。发送大量数据时应使用其他方案。

3. 数据格式选择

// JSON 格式（常用） navigator.sendBeacon('/api', JSON.stringify({ key: 'value' })); // FormData 格式（适合表单数据） const form = new FormData(); form.append('username', 'john'); form.append('action', 'login'); navigator.sendBeacon('/api', form); // Blob 格式（适合二进制数据） const blob = new Blob([arrayBuffer], { type: 'application/octet-stream' }); navigator.sendBeacon('/api', blob);

4. HTTPS 环境

建议在 HTTPS 环境下使用 sendBeacon，否则某些浏览器可能会降级或拒绝发送。

5. Analytics 埋点示例

// 页面浏览埋点 const trackPageView = () => { navigator.sendBeacon('/analytics', JSON.stringify({ event: 'page_view', page: location.pathname, referrer: document.referrer, timestamp: Date.now() })); }; // 点击事件埋点 document.addEventListener('click', (e) => { const target = e.target.closest('[data-track]'); if (target) { navigator.sendBeacon('/analytics', JSON.stringify({ event: 'click', action: target.dataset.track, x: e.clientX, y: e.clientY })); } }); // 页面卸载时自动发送 document.addEventListener('visibilitychange', () => { if (document.visibilityState === 'hidden') { trackPageView(); } });

6. 浏览器支持检测

if (navigator.sendBeacon) { navigator.sendBeacon('/analytics', data); } else { // fallback: 使用 fetch + keepalive fetch('/analytics', { method: 'POST', keepalive: true, body: data }); }
