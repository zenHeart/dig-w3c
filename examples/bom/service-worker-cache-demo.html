Service Worker 与 Cache Storage 交互演示

Service Worker 简介

Service Worker 是浏览器在后台运行的脚本，独立于网页面，提供离线体验、拦截网络请求等功能。

独立线程

运行在浏览器独立线程，不阻塞主线程

事件驱动

基于事件机制：install, activate, fetch

离线能力

拦截网络请求，提供缓存内容

HTTPS only

仅在 HTTPS 或 localhost 下可用

Cache Storage API

用于存储 Request/Response 对象对，通常与 Service Worker 配合使用。

方法说明
caches.open()打开或创建指定名称的缓存
caches.keys()获取所有缓存名称
caches.delete()删除指定缓存
cache.match()查找匹配的缓存
cache.put()手动存储请求/响应对
cache.addAll()批量添加请求到缓存

生命周期代码

// sw.js - Service Worker 文件

// 1. install 事件 - 缓存静态资源
self.addEventListener('install', (event) => {
  event.waitUntil(
    caches.open('static-v1').then((cache) => {
      return cache.addAll(['/', '/index.html']);
    })
  );
  self.skipWaiting(); // 跳过等待，立即激活
});

// 2. activate 事件 - 清理旧缓存
self.addEventListener('activate', (event) => {
  event.waitUntil(
    caches.keys().then((cacheNames) => {
      return Promise.all(
        cacheNames
          .filter((name) => name !== 'static-v1')
          .map((name) => caches.delete(name))
      );
    })
  );
  self.clients.claim();
});

// 3. fetch 事件 - 拦截网络请求
self.addEventListener('fetch', (event) => {
  event.respondWith(
    caches.match(event.request).then((response) => {
      return response || fetch(event.request);
    })
  );
});

缓存策略对比

策略说明适用场景
Cache First缓存优先，失败时网络静态资源
Network First网络优先，失败时缓存API 数据
Stale-While-Revalidate先返回缓存，后台更新不频繁变化的数据
Network Only仅网络实时数据
Cache Only仅缓存完全离线

Cache First 策略

请求
|
缓存中有?
有 -> 返回缓存
没有 -> 请求网络
// Cache First 策略
self.addEventListener('fetch', (event) => {
  event.respondWith(
    caches.match(event.request).then((response) => {
      if (response) return response; // 命中缓存
      return fetch(event.request); // 未命中，发起请求
    })
  );
});

Network First 策略

请求
|
发起网络请求
成功 -> 返回 + 缓存
失败 -> 返回缓存
// Network First 策略
self.addEventListener('fetch', (event) => {
  event.respondWith(
    fetch(event.request)
      .then((response) => {
        if (response.ok) {
          caches.open('api-v1').then(cache => 
            cache.put(event.request, response.clone())
          );
        }
        return response;
      })
      .catch(() => caches.match(event.request))
  );
});

Cache API 演示

手动存储示例

// 手动存储自定义 Response
const cache = await caches.open('my-cache-v1');

// 创建自定义 Response
const request = new Request('/api/custom');
const response = new Response(
  JSON.stringify({ message: 'Hello from SW!' }),
  { headers: { 'Content-Type': 'application/json' } }
);

// 存储
await cache.put(request, response);

// 查找
const cached = await cache.match('/api/custom');
const data = await cached.json();
console.log(data.message); // "Hello from SW!"

完整离线应用代码

// sw.js - 离线应用示例
const CACHE_NAME = 'offline-app-v1';
const STATIC_ASSETS = ['/', '/index.html', '/offline.html'];

// 安装
self.addEventListener('install', (event) => {
  event.waitUntil(
    caches.open(CACHE_NAME).then(cache => cache.addAll(STATIC_ASSETS))
  );
  self.skipWaiting();
});

// 激活
self.addEventListener('activate', (event) => {
  event.waitUntil(
    caches.keys().then(names => 
      Promise.all(names.filter(n => n !== CACHE_NAME).map(n => caches.delete(n)))
    )
  );
  self.clients.claim();
});

// 拦截请求
self.addEventListener('fetch', (event) => {
  event.respondWith(
    fetch(event.request)
      .then(response => {
        if (response.ok) {
          caches.open(CACHE_NAME).then(c => c.put(event.request, response.clone()));
        }
        return response;
      })
      .catch(() => caches.match(event.request).then(r => r || caches.match('/offline.html')))
  );
});
