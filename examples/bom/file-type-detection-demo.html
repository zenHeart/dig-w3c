🤯 什么是 MIME Sniffing？

当服务器没有正确设置 Content-Type 时，浏览器会根据文件内容推断类型。

🔬 Sniffing 规则详解

规则 1: 检查 HTML 特征

// 文件开头检测到这些字节模式： 3C 21 44 4F 43 54 59 50 45 → " → HTML 3C 68 74 6D 6C 3E → "<html>" → HTML 3C 21 2D 2D → <!-- → HTML

规则 2: 检查图片签名

89 50 4E 47 0D 0A 1A 0A → PNG 图片 FF D8 FF → JPEG 图片 47 49 46 38 39 61 → GIF89a 图片 25 50 44 46 → PDF 文档

⚠️ MIME Sniffing 安全风险

🎯 攻击场景：恶意文件伪装

1. 攻击者上传包含恶意 HTML 的"图片"文件

2. 服务器 Content-Type 设置为 image/png（错误）

3. 浏览器读取内容，发现是 HTML，执行恶意脚本

XSS 攻击成功！

✅ 防护方案：X-Content-Type-Options

// 服务器响应头 X-Content-Type-Options: nosniff // 效果： // - 浏览器严格遵循 Content-Type // - 不会根据内容推断类型 // - image/png 始终作为图片处理，不会执行 HTML

🔐 什么是文件签名（Magic Bytes）？

文件签名是文件开头的几个特殊字节，用于唯一标识文件类型。这是最可靠的文件类型识别方式。

最可靠：文件签名 服务器可伪造：Content-Type 最不可靠：URL 扩展名

💻 JavaScript 检测文件签名

// FileReader 读取文件头部字节 const reader = new FileReader(); reader.onload = (e) => { const bytes = new Uint8Array(e.target.result); const header = Array.from(bytes) .map(b => b.toString(16).padStart(2, '0')) .join(' '); // 检测签名 if (header.startsWith('89 50 4e 47')) return 'image/png'; if (header.startsWith('ff d8 ff')) return 'image/jpeg'; if (header.startsWith('47 49 46 38')) return 'image/gif'; if (header.startsWith('25 50 44 46')) return 'application/pdf'; };

🛡️ 文件类型识别安全策略

1. 启用 X-Content-Type-Options

// Express.js app.use((req, res, next) => { res.set('X-Content-Type-Options', 'nosniff'); next(); });

2. 服务端验证文件签名

// Node.js 文件上传安全检查 async function validateFileSignature(fileBuffer) { const header = fileBuffer.slice(0, 8).toString('hex'); const ALLOWED = { '89504e47': 'image/png', 'ffd8ff': 'image/jpeg', '47494638': 'image/gif', '25504446': 'application/pdf', }; for (const [sig, type] of Object.entries(ALLOWED)) { if (header.startsWith(sig)) return { valid: true, type }; } return { valid: false, error: 'Invalid file signature' }; }

3. 文件上传最佳实践

1. 扩展名白名单
.jpg, .png, .gif, .pdf
2. MIME type 检查
image/jpeg, image/png
3. 文件签名验证
Magic Bytes 检查
4. 文件重命名
不用用户提供的名称

⚠️ 常见安全错误

❌ 仅检查扩展名
攻击者可上传 malicious.php.jpg
扩展名是 .jpg，但内容是 PHP
❌ 仅检查 MIME type
浏览器可伪造 Content-Type
攻击者构造请求头声称是图片
✅ 检查文件签名
读取文件实际内容
服务端验证，不可伪造
