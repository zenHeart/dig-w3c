渲染计算过程

设备devicePixelRatio计算物理像素结果

0.6px 渲染解决方案

方案一：直接使用 0.6px（推荐）

现代浏览器基本都支持小于 1px 的 border-width

.rule { border-width: 0.6px; }
兼容性：现代浏览器 性能最优

方案二：box-shadow

利用 box-shadow 实现细线效果

.rule { box-shadow: 0 0.6px 0 #000; }
兼容性：全部

方案三：transform: scale

使用 transform 缩放 1px 的边框

.rule { border-width: 1px; transform: scaleY(0.6); transform-origin: top; }
兼容性：全部 注意定位

方案四：渐变模拟

使用线性渐变创建亚像素效果

.rule { background: linear-gradient(to bottom, transparent 0%, transparent 40%, #000 40%, #000 60%, transparent 60%, transparent 100%); background-size: 100% 1px; background-repeat: no-repeat; }
兼容性：全部

自测题

Q1: devicePixelRatio=2 的屏幕上，0.6px 边框实际渲染为多少物理像素？

Q2: 0.6px 在标准屏幕（dpr=1）上可能完全不显示的原因？

Q3: 物理像素的子像素有哪些？

答案

Q1: B - 0.6 × 2 = 1.2 物理像素，浏览器会进行抗锯齿处理

Q2: B - 0.6px × 1 = 0.6px，浏览器可能取整为 0px 导致不显示

Q3: A - 物理像素由 R（红）、G（绿）、B（蓝）三个子像素组成
