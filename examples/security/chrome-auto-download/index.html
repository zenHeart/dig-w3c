2. 自动下载触发机制对比

触发方式是否触发下载说明
<a download>✅ 是下载属性直接触发
location.href = url✅ 是简单文件下载
Blob URL + click✅ 是程序生成文件下载
<iframe>⚠️ 视情况需配合服务端 attachment 头
HTTP Content-Disposition: attachment✅ 是服务端强制下载

4. CSP 对下载的影响

CSP 可限制（间接）

object-src frame-src form-action 
Content-Security-Policy: object-src 'none'

阻止通过 object/embed/iframe 触发的恶意下载

CSP 无法限制

<a download> location.href Blob URL 
// CSP 无法直接控制 download 属性
<a href="evil.exe" download>

download 属性不受 CSP 控制，需配合其他策略

5. JavaScript 检测/控制下载

chrome.downloads API 示例（扩展）

chrome.downloads.onCreated.addListener((item) => {
  if (item.url.includes('malware')) {
    chrome.downloads.cancel(item.id)
    log('❌ 已阻止恶意文件下载')
  }
})

chrome.downloads.onChanged.addListener((delta) => {
  if (delta.state?.current === 'complete') {
    log(`✅ 下载完成: ${delta.filename}`)
  }
})
