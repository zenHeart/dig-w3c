CSP 内容安全策略

⚠️ 无 CSP 保护

💡 无 CSP 时，浏览器执行任何来源的脚本

✅ 严格 CSP 策略

default-src 'self'; script-src 'self' 'nonce-xyz'; style-src 'self' 'unsafe-inline'
🔒 只有 nonce='xyz' 的内联脚本被允许执行
