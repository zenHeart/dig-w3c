什么是定义列表？

<dl> (Definition List) 是 HTML 中用于展示键值对或术语定义的语义化标签组合。

标签全称作用类比
<dl>Definition List定义列表容器整个表格
<dt>Definition Term定义术语（键）表头单元格
<dd>Definition Description定义描述（值）表格单元格
快速示例
<dl>
  <dt>HTML</dt>
  <dd>超文本标记语言</dd>
  <dt>CSS</dt>
  <dd>层叠样式表</dd>
</dl>

dl vs ul vs ol — 选型决策表
列表类型HTML 标签语义含义适用场景
定义列表 <dl> 键值对 / 术语定义 名词—解释对应关系
无序列表 <ul> 一组相关条目 无顺序要求的项
有序列表 <ol> 编号序列 有顺序/排名要求的项
常见错误用法
  • 用 <div> 替代 <dl> — 失去语义
  • 用 <table> 展示键值对 — 表格用于行列数据，不是键值
  • 用 <ul> 写"名称: 值"字符串 — 语义不当
  • <dl> 内直接放文本不带 <dt>/<dd> — 不规范
