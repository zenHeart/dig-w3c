💻 Tab 2: 代码示例

HTML 结构

<!-- 基本用法 -->
<details>
  <summary>点击展开</summary>
  <p>这里是隐藏的内容</p>
</details>

<!-- 默认展开 -->
<details open>
  <summary>默认展开</summary>
  <p>页面加载时显示</p>
</details>

CSS 动画

/* 使用 Grid 实现动画 */
details {
  display: grid;
  grid-template-rows: 0fr;
  transition: grid-template-rows 0.3s ease;
}

details[open] {
  grid-template-rows: 1fr;
}

summary, details > div {
  overflow: hidden;
}

JavaScript 事件

const details = document.querySelector('details');

details.addEventListener('toggle', (e) => {
  if (details.open) {
    console.log('展开');
  } else {
    console.log('折叠');
  }
});

🎯 Tab 3: 实用场景

FAQ 折叠面板

什么是 HTML5?

HTML5 是 HTML 的第五个主要版本,引入了许多新特性,如语义化标签、原生视频/音频支持、Canvas 绘图等。

<details> 和 <dialog> 有什么区别?

<details> 用于折叠/展开内容,而 <dialog> 用于创建模态对话框。<dialog> 可以覆盖页面内容并创建叠加层。

如何添加展开/折叠动画?

可以使用 CSS Grid 的 grid-template-rows 技术实现平滑动画效果,或者使用 max-height 配合 transition。
