FAQ 问答对

问答场景
什么是 HTML？
HTML 是超文本标记语言，用于定义网页的结构和内容。
HTML 和 HTML5 有什么区别？
HTML5 是 HTML 的最新版本，引入了新的语义元素（如 article、section）、原生多媒体支持（audio、video）和 Canvas 绘图能力。
如何选择 ul 和 dl？
如果列表项之间是"名词—解释"的关系，用 dl；如果是"条目—条目"的关系，用 ul 或 ol。
