# 序号

**详解序号标签使用**

----

## 概述

ul(unordered lists) 无序标签,用于描述一个列表。
例如订单等。

## 核心标签

## ol(ordered list) 
有序标签,用于描述一个存在顺序的标签序列，
例如排名等。内部采用 li(list item) 标签表示单一项

## dl(definition list)
定义列表，用于展示键值对或术语定义。
- `<dl>` — Definition List，定义列表容器
- `<dt>` — Definition Term，定义术语（键）
- `<dd>` — Definition Description，定义描述（值）

适用场景：元数据、术语表、FAQ、配置项
