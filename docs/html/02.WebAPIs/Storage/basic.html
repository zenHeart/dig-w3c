sessionStorage vs localStorage 关键区别

  • 生命周期：sessionStorage 在标签页关闭后自动清除；localStorage 永久保存
  • 跨标签页：sessionStorage 不跨标签页共享；localStorage 跨所有标签页共享
  • 事件监听：sessionStorage 不触发 storage 事件；localStorage 会触发

选型决策树

  1. 需要存储 字符串/简单配置？
    • 是 → 标签页关闭后需要保留？
      • 是 → localStorage
      • 否 → sessionStorage
  2. 需要存储 大量结构化数据？
    • 是 → 需要索引/事务/查询能力？
      • 是 → IndexedDB
  3. 考虑 性能？
    • 同步 API 阻塞主线程 → 大数据用 IndexedDB
  4. 考虑 兼容性？
    • 所有现代浏览器都支持三者

常见踩坑

问题原因解决方案
容量超限 (QuotaExceededError)数据超过 5-10MB使用 IndexedDB 或清理旧数据
存储 "[object Object]"直接存储对象未序列化使用 JSON.stringify/parse
跨域访问失败同源策略限制确保协议+域名+端口一致
数据不是实时的sessionStorage 不跨标签页同步使用 localStorage 或 postMessage
IndexedDB 查询慢未建立索引使用 createIndex 创建索引
