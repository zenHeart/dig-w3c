3. lastIndex — g flag 循环 vs y flag 粘滞

g
点击运行查看结果...
g：循环匹配所有结果，自动推进 lastIndex
y：严格从 lastIndex 开始匹配，不向前扫描
g + y：sticky 优先，只从 lastIndex 开始（不循环）
