🔮 JavaScript Symbol 交互演示

1. Symbol 创建与唯一性

核心概念：每次 Symbol() 调用创建唯一值，即使描述相同也不相等。
const s1 = Symbol('name'); const s2 = Symbol('name'); // s1 === s2 → false

2. Symbol.for() 全局注册表

核心概念：Symbol.for() 在全局注册表中查找或创建符号，实现跨模块共享。
const global1 = Symbol.for('globalKey'); const global2 = Symbol.for('globalKey'); // global1 === global2 → true // Symbol.keyFor() 查询注册的键 Symbol.keyFor(global1); // 'globalKey'

3. Symbol.iterator - 自定义迭代器

核心概念：为对象定义 [Symbol.iterator]() 方法，使其可用于 for...of 和 ... 扩展。
const range = { start: 1, end: 5, [Symbol.iterator]() { let current = this.start; return { next() { if (current <= this.start + this.end - 1) { return { value: current++, done: false }; } return { value: undefined, done: true }; } }; } };

4. Symbol.toStringTag - 定制 toString 标签

核心概念：[Symbol.toStringTag] 定制 Object.prototype.toString() 的返回内容。
const person = { name: 'Alice', [Symbol.toStringTag]: 'Person' }; Object.prototype.toString.call(person); // '[object Person]'

5. Symbol.hasInstance - 定制 instanceof

核心概念：[Symbol.hasInstance] 允许自定义 instanceof 的判断逻辑。
class EvenNumbers { static [Symbol.hasInstance](num) { return typeof num === 'number' && num % 2 === 0; } } 42 instanceof EvenNumbers; // true 37 instanceof EvenNumbers; // false

6. Symbol.toPrimitive - 类型转换

核心概念：[Symbol.toPrimitive] 定义对象转换为基本类型时的行为（string/number/default）。
const voucher = { value: 100, [Symbol.toPrimitive](hint) { switch(hint) { case 'string': return `¥${this.value}`; case 'number': return this.value; default: return 'voucher'; } } };

7. Symbol 实现"私有"属性

核心概念：Symbol 属性不会出现在 Object.keys() 中，可用于模拟私有属性。
const _secret = Symbol('secret'); class SecureBox { constructor(data) { this.public = data; this[_secret] = 'hidden value'; } }

8. Symbol.isConcatSpreadable - 控制数组展开

核心概念：[Symbol.isConcatSpreadable] 控制 Array.concat() 是否展开数组。
const arr = [1, 2]; arr[Symbol.isConcatSpreadable] = false; [0].concat(arr); // [0, [1, 2]] - 不展开

9. 获取对象的 Symbol 属性

核心概念：Object.getOwnPropertySymbols() 和 Reflect.ownKeys() 可枚举 Symbol 属性。
const a = Symbol('a'); const b = Symbol('b'); const obj = { [a]: '1', [b]: '2', c: '3' }; Object.keys(obj); // ['c'] Object.getOwnPropertySymbols(obj); // [Symbol(a), Symbol(b)] Reflect.ownKeys(obj); // [Symbol(a), Symbol(b), 'c']
