# Data Visualization Catalogue（数据可视化目录）

> 参考：[datavizcatalogue.com](https://datavizcatalogue.com) — 一个按功能分类的数据可视化图表百科全书

## 概述

Data Visualization Catalogue 是一个在线图表百科全书，由 Severino Ribecca 创建，旨在帮助人们根据数据的性质和想要传达的信息，选择合适的可视化图表。

核心特点：
- **按功能分类**：不按图表形状（如柱状图、饼图），而按**数据关系类型**分类
- **搜索导向**：用户可以搜索想要完成的任务（如"比较数据"、"显示比例"），系统推荐适合的图表
- **详细说明**：每个图表都有使用场景、优缺点、最佳实践说明

## 按数据关系分类

### 1. 比较（Comparison）

适用于：比较不同类别之间的值的大小关系。

| 图表 | 说明 | 适用场景 |
|------|------|----------|
| **柱状图** Bar Chart | 用柱子高度表示数值大小 | 类别不多（<10）时的离散比较 |
| **分组柱状图** Grouped Bar Chart | 每组多个柱子 | 多个子类别在同维度下的比较 |
| **堆叠柱状图** Stacked Bar Chart | 柱子堆叠显示组成 | 部分与整体的关系 + 类别比较 |
| **径向柱状图** Radial Bar Chart | 环形柱状图 | 空间利用更紧凑，适合仪表盘 |
| **南丁格尔玫瑰图** Nightingale Rose Chart | 极坐标下的面积图 | 周期数据比较（如24小时数据） |
| **词云** Word Cloud | 文字大小表示频率 | 文本数据高频词可视化 |
| **雷达图** Radar Chart | 多维数据轮廓对比 | 能力模型、特征对比 |
| **对比柱状图** Back-to-Back Bar Chart | 两组柱子背靠背 | 同一指标的正负值对比 |
| **子弹图** Bullet Graph | 柱状图 + 目标线 | 实际值 vs 目标值对比 |
| **山形图** Rug Plot | 迷你图，一维分布 | 快速展示数据分布密度 |

### 2. 分布（Distribution）

适用于：展示数据的分布形态、集中趋势、离散程度。

| 图表 | 说明 | 适用场景 |
|------|------|----------|
| **直方图** Histogram | 连续数据的频数分布 | 数据分布形态分析 |
| **箱线图** Box Plot | 显示中位数、四分位数、异常值 | 多组数据分布对比 |
| **小提琴图** Violin Plot | 箱线图 + 密度估计 | 分布形状的细节对比 |
| **密度图** Density Plot | 平滑的连续分布曲线 | 连续变量分布趋势 |
| **山脊图** Ridgeline Plot | 多个密度图垂直堆叠 | 多组时间序列分布变化 |
| **点图** Dot Plot | 每个点代表一个数据 | 小样本量（<50）的精确展示 |
| **茎叶图** Stem-and-Leaf Plot | 类似直方图但保留原始数值 | 数据保留到个位 |
| **触发散点图** Jittered Strip Plot | 散点加抖动避免重叠 | 大量数据点的分布 |
| **蜂群图** Beeswarm Plot | 点自动错开不重叠 | 小规模多组分布对比 |
| **QQ 图** Quantile-Quantile Plot | 检验数据是否服从某分布 | 正态性检验 |

### 3. 关系（Relationship）

适用于：展示两个或多个变量之间的关系。

| 图表 | 说明 | 适用场景 |
|------|------|----------|
| **散点图** Scatter Plot | X/Y 坐标表示两个变量 | 两连续变量的相关性分析 |
| **气泡图** Bubble Chart | 散点 + 第三维（点大小） | 三维数据（X/Y/大小） |
| **热力图** Heatmap | 颜色深浅表示数值 | 矩阵数据、相关性矩阵 |
| **相关矩阵** Correlation Matrix | 热力图的一种 | 多变量相关性一览 |
| **和弦图** Chord Diagram | 环形 + 弦线表示关系 | 网络关系、流量/流向 |
| **桑基图** Sankey Diagram | 流量宽度表示数量 | 能量/物质/成本流动 |
| **弧线图** Arc Diagram | 节点排列一线，弧线连接 | 网络关系、周期结构 |
| **矩阵图** Matrix Chart | 行列表格 + 颜色 | 关系强度可视化 |
| **网络图** Network Diagram | 节点 + 边 | 复杂网络关系 |
| **三元图** Ternary Plot | 等边三角形坐标 | 三组分比例数据 |
| **双轴图** Dual Axis Chart | 共享 X 轴的双 Y 轴 | 两组不同量级数据对比 |
| **日历热力图** Calendar Heatmap | 日历 + 热力颜色 | 随时间分布的事件密度 |

### 4. 构成（Composition）

适用于：展示整体与部分的关系。

| 图表 | 说明 | 适用场景 |
|------|------|----------|
| **饼图** Pie Chart | 扇形面积表示比例 | 少量类别（≤5）的比例展示 |
| **环形图** Donut Chart | 中心挖空的饼图 | 比例展示，中心可放总计 |
| **堆叠面积图** Stacked Area Chart | 面积堆叠随时间变化 | 部分随时间的构成变化 |
| **百分比堆叠面积图** 100% Stacked Area | 堆叠面积归一化为百分比 | 构成比例随时间的变化 |
| **堆叠柱状图** Stacked Bar Chart | 柱子内部分段 | 类别内部的构成比较 |
| **瀑布图** Waterfall Chart | 柱状递增/递减 | 数量增减过程的分解 |
| **漏斗图** Funnel Chart | 逐步递减的形状 | 转化/筛选过程的阶段 |
| **华夫图** Waffle Chart | 方形格子组成的比例图 | 单一比例的直观展示 |
| **树图** Treemap | 矩形嵌套表示层次构成 | 层次数据的比例构成 |
| **旭日图** Sunburst Chart | 多层环形图 | 层次数据的构成（中心向外） |
| **圆形打包** Circle Packing | 圆形嵌套（不相交） | 层次数据的构成（圆形版） |

### 5. 趋势（Trend）

适用于：展示数据随时间的变化。

| 图表 | 说明 | 适用场景 |
|------|------|----------|
| **折线图** Line Chart | 点 + 线段连接 | 时间序列趋势 |
| **面积图** Area Chart | 折线下方填充 | 趋势 + 总量展示 |
| **堆叠折线图** Multi-Line Chart | 多条折线 | 多系列趋势对比 |
| **柱线组合图** Combo Chart | 柱状图 + 折线图组合 | 不同量级趋势组合 |
| **日历热力图** Calendar Heatmap | 日历 + 颜色 | 长时间周期的事件分布 |
| **季节性图** Seasonplot | 按季节周期折叠 | 季节性模式识别 |
| **蜡烛图** Candlestick Chart | 开盘/收盘/高/低 | 金融数据 |
| **坡度图** Slope Chart | 两时间点的连线变化 | 前后状态对比 |

### 6. 地理/空间（Geospatial）

适用于：与地理位置相关的数据。

| 图表 | 说明 | 适用场景 |
|------|------|----------|
| ** choropleth map** Choropleth Map | 区域着色表示数值 | 区域统计数据 |
| **分级符号图** Graduated Symbol Map | 符号大小表示数量 | 点位数据的数量对比 |
| **热力图** Heat Map | 颜色表示密度/强度 | 密集点位数据的分布 |
| **六边形网格图** Hexbin Map | 六边形网格聚合 | 密集点位数据的区域统计 |
| **流向图** Flow Map | 箭头表示移动方向 | 迁移/物流/交通流向 |
| **点密度图** Dot Density Map | 每个点代表若干单位 | 人口等点分布 |
| **等值线图** Contour Map | 等值线连接相同值 | 高度/温度/压力等连续场 |

## 选择图表的决策树

```
你想要做什么？
├── 比较类别之间的值？
│   ├── 类别不多（<10）→ 柱状图
│   ├── 多个时间点 → 折线图
│   ├── 部分与整体 → 堆叠柱状图 / 饼图
│   └── 一维小样本 → 词云 / 雷达图
├── 查看数据分布？
│   ├── 连续数据 → 直方图 / 密度图
│   ├── 对比多组分布 → 箱线图 / 小提琴图
│   └── 大量数据点 → 蜂群图 / 触发散点图
├── 展示关系？
│   ├── 两连续变量 → 散点图
│   ├── 三维数据 → 气泡图
│   ├── 矩阵关系 → 热力图
│   └── 网络关系 → 网络图 / 弦图
├── 展示构成？
│   ├── 静态比例 → 饼图 / 环形图
│   ├── 随时间变化 → 堆叠面积图
│   └── 层次结构 → 树图 / 旭日图
├── 展示趋势？
│   ├── 单系列 → 折线图
│   ├── 多系列 → 多线图
│   └── 转化过程 → 漏斗图
└── 地理数据？
    ├── 区域统计 → 等值区域图（Choropleth）
    ├── 点位密度 → 热力图 / 六边形网格
    └── 移动流向 → 流向图
```

## 图表设计最佳实践

### 通用的"不要"

1. **不要用饼图比较太多类别**（超过 5 个几乎无法阅读）
2. **不要截断 Y 轴**：柱状图从 0 开始
3. **不要用 3D 效果**：扭曲数据比例
4. **不要用太多颜色**：造成视觉负担
5. **不要忽略数据密度**：散点图重叠时考虑抖动或透明度
6. **不要混淆比较基准**：堆叠图要明确基准线

### 颜色使用

| 用途 | 颜色建议 |
|------|----------|
| 类别区分 | 色调差异大的 4-8 色 |
| 数值大小 | 单色渐变（浅→深） |
| 正负对比 | 双色渐变（如蓝←白→红） |
| 警示/阈值 | 高对比色（如红/黄/绿） |

### 标签和注释

- **数据标签**：只在大值或关键点加标签，避免杂乱
- **图例**：放在图表下方或右侧，避免遮挡数据
- **标题**：简洁描述核心发现，而非图表类型
- **来源**：小字标注数据来源
